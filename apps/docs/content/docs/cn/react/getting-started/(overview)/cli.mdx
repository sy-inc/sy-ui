`sy-inc-cli`是官方命令行工具，提供了一整套命令，用于初始化、管理和优化你的 SY INC 项目。你可以 `install`、`uninstall` 或 `upgrade` 单个组件，检查项目健康状况，下载用于 AI 编程助手的文档，等等。

## 安装

环境要求：

- [Node.js 22.22.0 或更高版本](https://nodejs.org/en/)


### 全局安装

要全局安装 `sy-inc-cli`，请在终端中执行以下命令之一：


```npm
npm install sy-inc-cli@latest -g
```

### 无需安装直接使用

或者，你也可以在不进行全局安装的情况下使用 `sy-inc-cli`，运行以下命令之一即可：

<Tabs items={["pnpm", "npm", "yarn", "bun"]}>
  <Tab value="pnpm">
    ```bash
    pnpm dlx sy-inc-cli@latest
    ```
  </Tab>
  <Tab value="npm">
    ```bash
    npx sy-inc-cli@latest
    ```
  </Tab>
  <Tab value="yarn">
    ```bash
    yarn dlx sy-inc-cli@latest
    ```
  </Tab>
  <Tab value="bun">
    ```bash
    bunx sy-inc-cli@latest
    ```
  </Tab>
</Tabs>

## 快速开始

安装 `sy-inc-cli` 后，运行以下命令以查看可用命令：

```bash
sy-inc
```

将会输出如下帮助信息：

```bash
Usage: sy-inc [command]

Options:
  -v, --version                  Output the current version
  --no-cache                     Disable cache, by default data will be cached for 30m after the first request
  -d, --debug                    Debug mode will not install dependencies
  -h --help                      Display help information for commands

Commands:
  init [options] [projectName]   Initializes a new project
  install [options]              Installs @sy-inc/react and @sy-inc/styles to your project
  upgrade [options]              Upgrades @sy-inc/react and @sy-inc/styles to the latest versions

  list [options]                 Lists installed SY INC packages (@sy-inc/react, @sy-inc/styles)

  doctor [options]               Checks for issues in the project
  agents-md [options]            Downloads SY INC documentation for AI coding agents
  help [command]                 Display help for command
```

### init

使用 `init` 命令初始化一个新的 SY INC 项目。该命令会为你的项目完成必要的配置。

```bash
sy-inc init [options]
```

**选项：**

- `-t --template [string]` 新项目使用的模板，例如 app、pages、vite、react-router
- `-p --package [string]` 新项目使用的包管理器

### doctor

检查项目中存在的问题。
- 检查 `@sy-inc/react` 和 `@sy-inc/styles` 是否已安装
- 检查项目中是否安装了所需的 `对等依赖` 并满足最低版本要求


```bash
sy-inc doctor [options]
```

**选项：**

- `-p --packagePath` [string] package.json 文件的路径

**输出：**

如果项目中存在问题，`doctor` 命令将显示问题信息。

```bash
SY INC CLI <version>

SY INC CLI: ❌ Your project has 1 issue that require attention

❗️Issue 1: missingSyIncPackages

The following SY INC packages are not installed:
- @sy-inc/styles

Run `sy-inc install` to install them.
```

否则，`doctor` 命令将显示以下消息。

```bash
SY INC CLI <version>

✅ Your project has no detected issues.
```

### agents-md

下载用于 AI 编程助手（Claude、Cursor 等）的 SY INC 文档。该命令会从 SY INC 仓库克隆最新文档，并将一份精简索引注入到 `AGENTS.md` 或 `CLAUDE.md` 中，方便助手参考你项目中的 SY INC 配置。

```bash
sy-inc agents-md [options]
```

**选项：**

- `--react` [boolean] 仅包含 React 文档（一次只能选择一个文档库）
- `--native` [boolean] 仅包含 Native 文档
- `--migration` [boolean] 仅包含 SY INC v2 到 v3 的迁移文档
- `--output <file>` [string] 目标文件路径（例如 `AGENTS.md`、`CLAUDE.md`）
- `--ssh` [boolean] 使用 SSH 而非 HTTPS 进行 git clone

**示例：**

不带任何标志运行以进入交互模式：

```bash
sy-inc agents-md
```

将 React 文档下载到指定文件：

```bash
sy-inc agents-md --react --output AGENTS.md
```

下载 Native 或迁移文档：

```bash
sy-inc agents-md --native --output CLAUDE.md
sy-inc agents-md --migration --output AGENTS.md
```

**工作原理：**

1. 使用 git sparse-checkout 从 `v3` 分支克隆文档
2. 生成文档和示例文件的精简索引
3. 将该索引注入到你的 markdown 文件中，置于标记之间（`<!-- SY-INC-REACT-AGENTS-MD-START -->` / `<!-- SY-INC-REACT-AGENTS-MD-END -->`，Native 和 Migration 也有类似的标记）
4. 将 `.sy-inc-docs/` 添加到 `.gitignore`

`--react`、`--native` 和 `--migration` 一次只能选择其中一个。

更多详情请参阅 [AGENTS.md](/docs/react/getting-started/agents-md)。

<Callout>
  `agents-md` 命令会收集匿名使用数据（所选项、输出文件名、耗时、成功或错误）。设置 `SY_INC_ANALYTICS_DISABLED=1` 可以选择不参与。
</Callout>
