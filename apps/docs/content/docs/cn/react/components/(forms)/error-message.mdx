## 用法

```tsx
import { ErrorMessage } from '@sy-inc/react';
```

`ErrorMessage` 是基于 React Aria `Text` 组件、`errorMessage` slot 的底层组件，它总是渲染内容，自身不做任何关联。

> 校验错误请统一使用 [`FieldError`](/docs/components/field-error)——React Aria 字段、`TagGroup`、`Calendar`、`RangeCalendar` 及其他任何控件都适用。`ErrorMessage` 保留给需要裸 `errorMessage` slot 的自定义组合。

## 组件结构

```tsx
import { TagGroup, Tag, Label, Description, ErrorMessage } from '@sy-inc/react';

<TagGroup>
  <Label />
  <TagGroup.List>
    <Tag />
  </TagGroup.List>
  <Description />
  <ErrorMessage />
</TagGroup>
```

## 何时使用

优先使用 [`FieldError`](/docs/components/field-error)：只在有错误时渲染；在 React Aria 字段、`TagGroup`、`Calendar`、`RangeCalendar` 内自动关联到控件；放在其他控件旁边时通过 `id` + `aria-describedby` 关联。

## ErrorMessage 与 FieldError

| 组件 | 何时渲染 | 与控件的关联 | 用途 |
|-----------|----------|------------------|---------------------|
| `FieldError` | 仅在有错误时 | 字段、`TagGroup`、`Calendar`、`RangeCalendar` 内自动关联；其他地方通过 `aria-describedby` | 所有校验错误（推荐） |
| `ErrorMessage` | 总是 | 仅通过父组件的 `errorMessage` slot | 自定义组合 |

### 全局 CSS

可使用 `@layer components` 指令自定义 ErrorMessage 组件类。[了解更多](https://tailwindcss.com/docs/adding-custom-styles#adding-component-classes)。

```css
@layer components {
  .error-message {
    @apply text-sm font-medium text-danger;
  }
}
```

## 说明

`ErrorMessage` 基于 React Aria 的 `Text` 组件，`slot="errorMessage"`。可通过 `[slot=errorMessage]` CSS 选择器定位。

## 无障碍

ErrorMessage 组件通过以下方式增强无障碍性：

- 使用屏幕阅读器可识别的语义化 HTML
- 提供 `slot="errorMessage"` 属性以集成 React Aria
- 错误状态支持适当的文本对比度
- 遵循 WAI-ARIA 错误消息最佳实践
