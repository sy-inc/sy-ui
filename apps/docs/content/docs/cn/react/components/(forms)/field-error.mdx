## 用法

```tsx
import { FieldError } from '@sy-inc/react';
```

<ComponentPreview
  name="field-error-basic"
/>

FieldError 展示表单控件的错误消息，没有错误时不渲染。在 React Aria 字段（`TextField`、`Select`、`RadioGroup` 等）内，由字段的无效状态决定显示；放在其他控件旁边时，由传入的消息决定。参见[在 React Aria 字段之外使用](#在-react-aria-字段之外使用)。

## 示例

### 基础校验

```tsx
export function Basic() {
  const [value, setValue] = useState("");
  const isInvalid = value.length > 0 && value.length < 3;

  return (
    <TextField className="w-64" isInvalid={isInvalid}>
      <Label htmlFor="username">Username</Label>
      <Input
        id="username"
        placeholder="Enter username"
        value={value}
        onChange={(e) => setValue(e.target.value)}
      />
      <FieldError>Username must be at least 3 characters</FieldError>
    </TextField>
  );
}
```

### 动态错误信息

```tsx
<TextField isInvalid={errors.length > 0}>
  <Label>Password</Label>
  <Input type="password" />
  <FieldError>
    {(validation) => validation.validationErrors.join(', ')}
  </FieldError>
</TextField>
```

### 自定义校验逻辑

```tsx
function EmailField() {
  const [email, setEmail] = useState('');
  const isInvalid = email.length > 0 && !email.includes('@');

  return (
    <TextField isInvalid={isInvalid}>
      <Label>Email</Label>
      <Input
        type="email"
        value={email}
        onChange={(e) => setEmail(e.target.value)}
      />
      <FieldError>Email must include @ symbol</FieldError>
    </TextField>
  );
}
```

### 多条错误信息

```tsx
<TextField isInvalid={hasErrors}>
  <Label>Username</Label>
  <Input />
  <FieldError>
    {errors.map((error, i) => (
      <div key={i}>{error}</div>
    ))}
  </FieldError>
</TextField>
```

### 在 React Aria 字段之外使用

同一个 `FieldError` 也可以放在不是 React Aria 字段的控件旁边——`InputOTP`、`InputPhone`、多选 `ListBox`。这时没有字段状态可读，内容本身就是错误：传入消息就显示；什么都不传（`undefined`、`null`、`false`、`""`、`[]`）就不渲染。

```tsx
<InputOTP aria-describedby={error ? "code-error" : undefined} isInvalid={!!error} maxLength={6}>
  ...
</InputOTP>
<FieldError id="code-error">{error}</FieldError>
```

React Aria 字段会自动把消息关联到输入框。在其他地方，给 `FieldError` 一个 `id`，让控件的 `aria-describedby` 指向它，并把控件标记为无效（`isInvalid`；没有该属性的控件用 `aria-invalid`）。

`<FieldError>{error}</FieldError>` 在两种场景下写法一致——放在字段内时，给字段配上 `isInvalid={!!error}` 即可。

## API 参考

### FieldError

| Prop | 类型 | 默认值 | 描述 |
|------|------|--------|------|
| `className` | `string` | - | 附加 CSS 类 |
| `children` | `ReactNode \| ((validation: ValidationResult) => ReactNode)` | - | 错误消息内容或 render 函数。在 React Aria 字段之外，内容为空时不渲染 |
| `id` | `string` | - | 在 React Aria 字段之外，供控件的 `aria-describedby` 指向 |

## 无障碍

FieldError 组件通过以下方式确保无障碍性：

- 在 React Aria 字段内，通过 `aria-describedby` 把消息关联到输入框，并且只在字段无效时渲染
- 在字段之外，只在有内容时渲染；用 `id` 加控件上的 `aria-describedby` 关联
- 隐藏的消息不渲染，读屏不会读到过期的错误
