## 用法

使用 Widget 将紧凑图表、指标或其他数据可视化与标题和图例分组。

```tsx
import { Description, Widget } from '@sy-inc/react';
```

## 基础示例

```tsx
<Widget>
  <Widget.Header>
    <Widget.Title>月度收入</Widget.Title>
    <Widget.Legend>
      <Widget.LegendItem color="var(--primary)">收入</Widget.LegendItem>
    </Widget.Legend>
  </Widget.Header>
  <Widget.Content>
    <svg aria-label="月度收入图表" viewBox="0 0 320 160" />
  </Widget.Content>
</Widget>
```

## 结构

- `Widget` 与 `Widget.Root` 渲染外层表面。
- `Widget.Header` 包含 `Widget.Title` 与可选的 `Widget.Legend`。
- `Widget.Content` 承载可视化。当 `Widget.Content` 内放置 `Table` 等需要贴边的内容时，传入 `className="p-0"`。
- `Widget.LegendItem` 根据必填的 `color` 和 children 渲染标记点与标签。

## API 参考

### Widget 与各 part

`Widget`、`Widget.Root`、`Widget.Header`、`Widget.Title`、`Widget.Content` 与 `Widget.Legend` 接受原生元素 props、`className` 和 `render`。`Widget.Title` 默认渲染 `h3`；其余 part 默认渲染 `div`。

| Part | 默认元素 | 说明 |
| --- | --- | --- |
| `Widget` / `Widget.Root` | `div` | 外层 secondary 表面。 |
| `Widget.Header` | `div` | 标题与图例所在行。 |
| `Widget.Title` | `h3` | Widget 标题。 |
| `Widget.Content` | `div` | 内层可视化表面。 |
| `Widget.Legend` | `div` | 图例项的 flex 行。 |

### Widget.LegendItem

| Prop | 类型 | 默认值 | 说明 |
| --- | --- | --- |
| `color` | `string` | 必填 | 用于 10px 标记点的任意有效 CSS color 值。 |
| `children` | `React.ReactNode` | 必填 | 可见的图例标签。 |
| `className` | `string` | — | 应用于图例项的附加 class。 |

## 事件

Widget 自身没有事件。请在 `Widget.Content` 中组合的交互元素上添加回调。

## 无障碍

- Widget 是结构性组件，没有隐含 landmark 或交互 role。
- `Widget.Title` 默认提供语义化 `h3`；应根据周围文档选择合适的标题级别。
- 当 SVG 或其他可视化表达信息时，应提供其自己的无障碍名称与说明。
- 不要只用图例颜色区分数据系列；保留可见的文字标签。

## Slots

Widget 暴露以下 `data-slot` hooks：`widget`、`widget-header`、`widget-title`、`widget-content`、`widget-legend`、`widget-legend-item`、`widget-legend-item-dot` 与 `widget-legend-item-label`。

## 与 Description 组合

Widget 不提供 description part。需要辅助文案时直接组合公共 `Description`；它会保留已有的 `data-slot="description"`，并可使用 12/16 muted 样式。

```tsx
<Widget.Header>
  <div>
    <Widget.Title>月度收入</Widget.Title>
    <Description className="leading-4">与上月相比。</Description>
  </div>
</Widget.Header>
```
