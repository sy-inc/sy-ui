## 用法

```tsx
import {MessageBubble} from "@sy-inc/react";
```

```tsx
<MessageBubble direction="sent">
  <MessageBubble.Content>
    <MessageBubble.Text>
      中午见。
      <MessageBubble.Time>11:42</MessageBubble.Time>
    </MessageBubble.Text>
  </MessageBubble.Content>
</MessageBubble>
```

## 组件结构

| 部件 | Slot | 说明 |
| --- | --- | --- |
| `MessageBubble` / `MessageBubble.Root` | `message-bubble` | 按 `direction` 对齐气泡的行容器。 |
| `MessageBubble.Content` | `message-bubble-content` | 有底色的气泡，容纳图片、`Text` 与 `Time`。 |
| `MessageBubble.Text` | `message-bubble-text` | 正文；纯图片消息可省略。 |
| `MessageBubble.Time` | `message-bubble-time` | 时间。 |

`Time` 采用绝对定位，因此同时渲染一份不可见的行内副本，为正文末行预留位置。把 `Time` 放进 `Text` 即可获得这份预留：能放下时留在末行，放不下时换到右对齐的新末行。纯图片消息则把 `Time` 直接放在 `Content` 中，此时预留被丢弃，时间浮在图片上。

## 图片与链接

图片作为 `Content` 的子节点组合；字符串保持原样，不解析 HTML、Markdown 或自动识别 URL。

```tsx
<MessageBubble direction="sent">
  <MessageBubble.Content>
    <img src="/photos/trip.jpg" alt="湖边的山景" width={600} height={400} loading="lazy" decoding="async" />
    <MessageBubble.Text>
      查看 <a href="https://example.com/trip">旅行计划</a>。
      <MessageBubble.Time>11:42</MessageBubble.Time>
    </MessageBubble.Text>
  </MessageBubble.Content>
</MessageBubble>
```

纯图片消息去掉 `Text`，把 `Time` 放在 `Content` 里：

```tsx
<MessageBubble>
  <MessageBubble.Content>
    <img src="/photos/trip.jpg" alt="湖边的山景" width={600} height={400} />
    <MessageBubble.Time>11:42</MessageBubble.Time>
  </MessageBubble.Content>
</MessageBubble>
```

为图片提供原始宽高可预留空间，避免加载时布局跳动；`loading` 与 `decoding` 由调用方控制。链接的 `href`、`target`、`rel` 也由调用方设置。

## 长消息列表

使用 `MessageList` 包裹消息，由组件提供底部跟随、悬浮向下箭头和点击后的平滑滚动。消费侧负责数据与最多保留 100 条的业务规则。

```tsx
import {MessageBubble, MessageList} from "@sy-inc/react";

<MessageList scrollToBottomLabel="回到底部" viewportProps={{"aria-label": "客服消息记录"}}>
  <MessageBubble>
    <MessageBubble.Content>
      <MessageBubble.Text>
        请帮我查询订单。
        <MessageBubble.Time>09:41</MessageBubble.Time>
      </MessageBubble.Text>
    </MessageBubble.Content>
  </MessageBubble>
  <MessageBubble direction="sent">
    <MessageBubble.Content>
      <MessageBubble.Text>
        好的，请稍等。
        <MessageBubble.Time>09:42</MessageBubble.Time>
      </MessageBubble.Text>
    </MessageBubble.Content>
  </MessageBubble>
</MessageList>
```

## API 参考

### MessageBubble.Root

| Prop | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `direction` | `"sent" \| "received"` | `"received"` | 控制对齐和表面样式。 |
| `className` | `string` | `""` | 仅合并到根节点的附加类。 |

`Content` 与 `Text` 接收原生 `div` 属性；`Time` 接收原生 `time` 属性，字符串子节点即时间文本。除 `direction` 外没有变体，也没有事件。

## 样式

可使用根节点的 `data-direction="sent"` 或 `data-direction="received"` 及已公开的 slots 定制后代：

```css
.message-bubble[data-direction="sent"] [data-slot="message-bubble-time"] {
  font-variant-numeric: tabular-nums;
}
```

received 气泡使用现有的 surface 与 foreground token。sent 气泡保留 `--accent-foreground`，并从 `--accent` 派生较低的 `oklch` 明度，因此在内置亮暗主题中保持 accent 表面与可读性，同时不新增组件 token。它保留空白与换行、会换行长 URL 或无空格文本；时间使用比正文更淡的颜色、12px 字号与常规字重。图片按容器宽度等比缩放，链接始终有下划线并支持可见焦点。它不管理消息列表滚动、头像、已读状态、回复、菜单、日期或时间格式化。

## 无障碍

根节点不添加交互角色、实时区域或自动播报。链接保留原生键盘行为；图片需要有意义的 `alt`。对话列表、地标、作者与更新语义由外层结构负责。
