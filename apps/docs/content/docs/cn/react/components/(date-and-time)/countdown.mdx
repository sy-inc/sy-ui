## 使用

在重复渲染之间保持截止时间稳定。下面的示例每次挂载时启动七天倒计时，与 Storybook 的 **7 Days** 示例一致。

```tsx
"use client";

import {Countdown} from "@sy-inc/react";
import {useState} from "react";

export default function SevenDays() {
  const [endDate] = useState(() => Date.now() + 7 * 24 * 60 * 60 * 1000);

  return <Countdown aria-label="剩余时间" endDate={endDate} size="lg" />;
}
```

对于所有用户共享的活动，请传入业务数据中的固定截止时间。数字时间戳单位为**毫秒**；日期字符串应包含时区，例如 `2027-01-01T00:00:00Z`。

## 结构

`Countdown`（也可使用 `Countdown.Root` 或具名导出的 `CountdownRoot`）渲染带计时器语义的 `span`。始终显示天、时、分、秒四组，即使天数归零也不移除分组。每组至少显示两位数字，天数支持超过两位。一天表示经过 24 小时，不按自然日边界计算。

时间分组和数字是内部实现，通过公开样式 slot 自定义，无需 context 或额外公开子组件。标签、Card、Surface 或 Button 使用现有组件在外层组合。

## 属性

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `endDate` | `Date \| string \| number` | 必填 | 绝对截止时间。 |
| `size` | `"sm" \| "md" \| "lg"` | `"md"` | 数字大小与间距。 |
| `animation` | `"slide" \| "none"` | `"slide"` | 数字纵向切换动画。 |
| `labels` | `Partial<Record<"days" \| "hours" \| "minutes" \| "seconds", string>>` | 英文单位名称 | 视觉与无障碍文本共用的单位标签。 |
| `completionContent` | `ReactNode` | — | 完成后替换四组零值；内容应适合放在 span 内。 |
| `onComplete` | `() => void` | — | 当前截止时间完成时调用一次；挂载时已过期也会调用。改变截止时间开启新一轮。 |
| `className` | `string` | — | 根节点样式。 |
| `ref` | `Ref<HTMLSpanElement>` | — | 根节点引用。 |

支持原生 span 属性，包括 `aria-label`、`aria-labelledby` 和 `dir`。导出类型为 `CountdownProps`、`CountdownRootProps` 与 `CountdownVariants`；`countdownVariants` 可从 `@sy-inc/react` 或 `@sy-inc/styles` 导入。组件也可从 `@sy-inc/react/countdown` 导入。

## 计时与完成

不足一秒的正剩余时间向上取整，过期后固定为零。每次更新根据截止时间和设备当前时间重新计算，回调延迟时不会仅减一秒。返回页面时也会刷新。改变 `endDate` 会取消原计划，卸载时清理定时器和监听器。

无效截止时间显示横线与 `data-state="invalid"`，不触发 `onComplete`。SSR 和首次 hydration 渲染横线及 `data-state="pending"`，挂载后开始计时，避免服务端和客户端时钟差异引起 hydration 不一致。

## 标签与动画

```tsx
<Countdown
  aria-label="倒计时"
  endDate="2027-01-01T00:00:00Z"
  labels={{days: "天", hours: "时", minutes: "分", seconds: "秒"}}
  animation="none"
/>
```

只有发生变化的数字播放动画。CSS 让不透明的数字缓慢起步、中段快速滚动、末尾缓慢停下，React 为每位最多保留两个字符，不依赖动画库。`prefers-reduced-motion: reduce` 会关闭动效，计时与完成回调继续正常工作。局部 CSS 变量 `--countdown-duration` 可调整动画时长，默认 `1s`。局部变量 `--countdown-easing` 默认使用 `cubic-bezier(1, 0, 0, 1)`。

## 无障碍

根节点使用 `role="timer"`，默认名称为可覆盖的 “Countdown”，并设置 `aria-live="off"`，避免每秒打断播报。一份视觉隐藏的文本暴露剩余时间，动画分组对辅助技术隐藏。单位默认使用英文，可通过 `labels` 翻译。计时器不增加焦点停靠点或键盘交互。

需要完成播报时，通过 `onComplete` 更新独立且持续挂载的 `role="status"` 区域，参见 **Completion** Story。组合进按钮时，为按钮提供明确的操作名称。

## 样式参考

稳定的 `data-slot` 包括 `countdown`、`countdown-accessible-text`、`countdown-segment`、`countdown-value`、`countdown-digit`、`countdown-glyph` 和 `countdown-label`。分组暴露 `data-unit="days | hours | minutes | seconds"`，根节点暴露 `data-state="pending | running | complete | invalid"`。
