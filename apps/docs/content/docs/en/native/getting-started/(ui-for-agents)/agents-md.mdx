Download SY INC Native documentation directly into your project for AI assistants to reference.

<Callout>
  **Note:** The `agents-md` command is specifically for SY INC React v3 and SY INC Native. Other CLI commands (like `add`, `init`, `upgrade`, etc.) are for SY INC v2 (for now).
</Callout>

### Usage

```bash
npx sy-inc-cli@latest agents-md --native
```

Or specify output file:

```bash
npx sy-inc-cli@latest agents-md --native --output AGENTS.md
```

### What It Does

- Downloads latest SY INC Native docs to `.sy-inc-docs/native/`
- Generates an index in `AGENTS.md` or `CLAUDE.md`
- Adds `.sy-inc-docs/` to `.gitignore` automatically

### Options

- `--native` - Download Native docs only
- `--output <files...>` - Target file(s) (e.g., `AGENTS.md` or `AGENTS.md CLAUDE.md`)
- `--ssh` - Use SSH for git clone

### Requirements

- Tailwind CSS >= v4 (via Uniwind)
