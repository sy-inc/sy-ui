## Usage

```tsx
import {MessageBubble} from "@sy-inc/react";
```

```tsx
<MessageBubble direction="sent">
  <MessageBubble.Content>
    <MessageBubble.Text>
      See you at noon.
      <MessageBubble.Time>11:42</MessageBubble.Time>
    </MessageBubble.Text>
  </MessageBubble.Content>
</MessageBubble>
```

## Anatomy

| Part | Slot | Description |
| --- | --- | --- |
| `MessageBubble` / `MessageBubble.Root` | `message-bubble` | The row that aligns the bubble by `direction`. |
| `MessageBubble.Content` | `message-bubble-content` | The painted bubble. Holds images, `Text`, and `Time`. |
| `MessageBubble.Text` | `message-bubble-text` | The message body. Omit it for an image-only bubble. |
| `MessageBubble.Time` | `message-bubble-time` | The timestamp. |

`Time` is absolutely positioned, so it also renders an invisible inline copy that reserves room on the last line of text. Put `Time` inside `Text` to get that reservation: it stays on the last line when it fits and otherwise moves to a right-aligned final line. Put it directly in `Content` for an image-only bubble, where the reservation is dropped and the timestamp floats over the picture.

## Images and links

Compose images as children of `Content`. Strings remain literal: HTML, Markdown, and automatic URL linking are not parsed.

```tsx
<MessageBubble direction="sent">
  <MessageBubble.Content>
    <img src="/photos/trip.jpg" alt="Mountains beside a lake" width={600} height={400} loading="lazy" decoding="async" />
    <MessageBubble.Text>
      See the <a href="https://example.com/trip">trip itinerary</a>.
      <MessageBubble.Time>11:42</MessageBubble.Time>
    </MessageBubble.Text>
  </MessageBubble.Content>
</MessageBubble>
```

For an image-only message, drop `Text` and place `Time` in `Content`:

```tsx
<MessageBubble>
  <MessageBubble.Content>
    <img src="/photos/trip.jpg" alt="Mountains beside a lake" width={600} height={400} />
    <MessageBubble.Time>11:42</MessageBubble.Time>
  </MessageBubble.Content>
</MessageBubble>
```

Supply intrinsic image dimensions to reserve space and prevent layout shifts. The caller controls `loading`, `decoding`, and link attributes such as `href`, `target`, and `rel`.

## Long conversations

Wrap messages in `MessageList` for bottom following, a floating down arrow, and smooth scrolling on click. The consumer owns the data and any limit such as retaining the latest 100 messages.

```tsx
import {MessageBubble, MessageList} from "@sy-inc/react";

<MessageList viewportProps={{"aria-label": "Customer messages"}}>
  <MessageBubble>
    <MessageBubble.Content>
      <MessageBubble.Text>
        Please check my order.
        <MessageBubble.Time>09:41</MessageBubble.Time>
      </MessageBubble.Text>
    </MessageBubble.Content>
  </MessageBubble>
  <MessageBubble direction="sent">
    <MessageBubble.Content>
      <MessageBubble.Text>
        Of course, one moment.
        <MessageBubble.Time>09:42</MessageBubble.Time>
      </MessageBubble.Text>
    </MessageBubble.Content>
  </MessageBubble>
</MessageList>
```

## API Reference

### MessageBubble.Root

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `direction` | `"sent" \| "received"` | `"received"` | Controls alignment and surface treatment. |
| `className` | `string` | `""` | Classes merged onto the root only. |

`Content` and `Text` take the native `div` props; `Time` takes the native `time` props and a string child used as the timestamp. There are no variants beyond `direction` and no events.

## Styling

Use `data-direction="sent"` or `data-direction="received"` on the root and the documented slots for descendant customization:

```css
.message-bubble[data-direction="sent"] [data-slot="message-bubble-time"] {
  font-variant-numeric: tabular-nums;
}
```

The received bubble uses the existing surface and foreground tokens. The sent bubble derives a darker `oklch` lightness from `--accent` while retaining `--accent-foreground`; this keeps the accent treatment readable in both built-in themes without adding a component token. It preserves whitespace and newlines, wraps long URLs and unspaced content, and uses a muted 12px, regular-weight timestamp. Images scale proportionally to fit the bubble; links have persistent underlines and visible focus. It does not manage message lists, scrolling, avatars, receipts, replies, menus, dates, or time formatting.

## Accessibility

The root adds no interactive role, live region, or announcements. Links retain native keyboard behavior; images need meaningful `alt` text. The surrounding conversation supplies list, landmark, author, and update semantics.
