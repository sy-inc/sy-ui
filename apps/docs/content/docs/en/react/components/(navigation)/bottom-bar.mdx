## Usage

```tsx
import {BottomBar} from '@sy-inc/react';

export default function Example({pathname}: {pathname: string}) {
  return (
    <BottomBar aria-label="Primary navigation">
      <BottomBar.Item href="/home" isActive={pathname === '/home'}>
        <BottomBar.Icon>⌂</BottomBar.Icon>
        <BottomBar.Label>Home</BottomBar.Label>
      </BottomBar.Item>
      <BottomBar.Item href="/search" isActive={pathname.startsWith('/search')}>
        <BottomBar.Icon>⌕</BottomBar.Icon>
        <BottomBar.Label>Search</BottomBar.Label>
      </BottomBar.Item>
    </BottomBar>
  );
}
```

## Anatomy

```tsx
<BottomBar>
  <BottomBar.Item href="/destination" isActive>
    <BottomBar.Icon />
    <BottomBar.Label />
  </BottomBar.Item>
</BottomBar>
```

Each item declares whether it is the current destination with `isActive`. When the current page is not in the bar, leave every item inactive: nothing is highlighted and every item stays reachable with `Tab`.

An item with `href` renders a link. Wrap the app in `RouterProvider` to route these links through a client-side router. An item without `href` renders a button; use `onPress` to switch views within a page.

## Key props and behavior

| Prop | Type | Default | Description |
|---|---|---|---|
| `position` | `"fixed" \| "sticky" \| "static"` | `"fixed"` | Placement strategy. |
| `variant` | `"floating" \| "edge"` | `"floating"` | Container treatment. |
| `selectionStyle` | `"color" \| "indicator" \| "underline"` | `"indicator"` | Active-item treatment. The indicator slides between items when the active item changes. |

| Item prop | Type | Default | Description |
|---|---|---|---|
| `href` | `string` | - | Renders a link. Without it, the item renders a button. |
| `isActive` | `boolean` | `false` | Marks the current destination. |
| `isDisabled` | `boolean` | `false` | Disables the item. |
| `onPress` | `(e: PressEvent) => void` | - | Called when the item is pressed. |

Item children may be a render function receiving `{isActive, isHovered, isPressed, isFocused, isFocusVisible, isDisabled}`.

## Accessibility

The root renders a `navigation` landmark containing a list. The active item gets `aria-current="page"` on links and `aria-current="true"` on buttons. Always provide `aria-label` or `aria-labelledby` on the root, keep a text label (or `aria-label`) for every destination, and treat `BottomBar.Icon` as decorative—it is automatically hidden from assistive technology.
