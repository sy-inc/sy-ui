## Anatomy

```tsx
<Segment aria-label="Dashboard navigation" defaultSelectedKey="dashboard" separators>
  <Segment.Item id="dashboard">Dashboard</Segment.Item>
  <Segment.Item id="analytics">Analytics</Segment.Item>
</Segment>
```

`Segment.Item` automatically renders its selection indicator. Set `separators` on `Segment` to show CSS separators between items. Separators beside the selected item are hidden automatically.

## CSS Classes

Stable slots are `segment`, `segment-item`, and `segment-indicator`. The matching BEM classes are `.segment`, `.segment__item`, and `.segment__indicator`, with `--sm`, `--md`, `--lg`, `--ghost`, and `--separators` modifiers.

## API Reference

### Segment

Built on React Aria `ToggleButtonGroup` and fixed to single selection. `selectedKey` is `Key | null`; `defaultSelectedKey` is `Key`; `onSelectionChange` receives only a `Key`. A selected item cannot be cleared by pressing it again, so the callback never receives `undefined`.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `variant` | `"default" \| "ghost"` | `"default"` | Visual treatment |
| `size` | `"sm" \| "md" \| "lg"` | `"md"` | Item height: 28px, 32px, or 40px |
| `selectedKey` | `Key \| null` | - | Controlled selection |
| `defaultSelectedKey` | `Key` | - | Initial uncontrolled selection |
| `onSelectionChange` | `(key: Key) => void` | - | Called with the new key |
| `separators` | `boolean` | `false` | Shows CSS separators between items |
| `isDisabled` | `boolean` | `false` | Disables every item |

### Segment.Item

Accepts React Aria ToggleButton props including `id`, `isDisabled`, `ref`, icons, and children as a React node or render function. Give icon-only items an `aria-label`.

## Accessibility

Segment uses a button-based radiogroup, not tabs. Give the group an accessible name with `aria-label` or `aria-labelledby`. Arrow keys move focus; Space and Enter select the focused option. Keyboard focus is visibly indicated.

## Related Components

Use `ToggleButtonGroup` for multiple independent toggle choices and `Tabs` when each choice controls a panel of content.
