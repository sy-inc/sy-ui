## Usage

Use `Drawer` for a panel that enters from an edge of the viewport. It supports pointer dragging,
optional snap points, nested drawers, and modal or non-modal presentation.

```tsx
import {Button, Drawer} from "@sy-inc/react";
```

<ComponentPreview name="drawer-basic" />

## Anatomy

```tsx
import {Button, Drawer} from "@sy-inc/react";

export default () => (
  <Drawer>
    <Button variant="secondary">Open Drawer</Button>
    <Drawer.Backdrop>
      <Drawer.Content>
        <Drawer.Dialog>
          <Drawer.Handle /> {/* Optional drag handle */}
          <Drawer.CloseTrigger /> {/* Optional close button */}
          <Drawer.Header>
            <Drawer.Heading>Drawer title</Drawer.Heading>
          </Drawer.Header>
          <Drawer.Body>Drawer content</Drawer.Body>
          <Drawer.Footer>Drawer actions</Drawer.Footer>
        </Drawer.Dialog>
      </Drawer.Content>
    </Drawer.Backdrop>
  </Drawer>
);
```

`Drawer` is also available as `Drawer.Root`. Render a `Drawer` inside another drawer to nest it.

### Snap Points

Snap points describe the visible extent of the dialog along its active axis:

- A number must be between `0` and `1` and is a relative fraction (`0.5` is `50%`).
- A value ending in `%` is relative to the drawer dimension.
- A value ending in `px` is an absolute dimension.
- Points must be strictly increasing and a list cannot mix `px` with relative values (numbers or
  `%`).

When `defaultActiveSnapPoint` is omitted, the last snap point is selected. Pass
`activeSnapPoint` with `onActiveSnapPointChange` for a controlled snap point.

<ComponentPreview name="drawer-snap-points" />

### Advanced

The advanced example matches the official three-level nested composition. A `Drawer` rendered
inside another `Drawer` is nested automatically: each parent panel scales and shifts while its child
is open.

The parent panel gets `[data-nested-open="true"]` while a child is open. To keep a parent still,
override the recede styles on its `Drawer.Content`:

```tsx
<Drawer.Content className="data-[nested-open=true]:transform-none data-[nested-open=true]:overflow-visible data-[nested-open=true]:rounded-none">
```

## Styling Reference

SY INC follows the [BEM](https://getbem.com/) methodology so component parts and states can be
customized consistently.

### CSS Classes

The Drawer component uses these classes ([View source styles](https://github.com/sy-inc/sy-inc/blob/v3/packages/styles/components/drawer.css)):

#### Base Classes [!toc]

- `.drawer__trigger` - Trigger button rendered by `Drawer.Trigger`
- `.drawer__backdrop` - Overlay layer behind the drawer
- `.drawer__content` - Fixed positioning wrapper for the panel
- `.drawer__dialog` - The drawer panel itself
- `.drawer__header` - Header section for titles
- `.drawer__heading` - Main title text
- `.drawer__body` - Scrollable body content
- `.drawer__footer` - Action area
- `.drawer__handle` - Drag handle container
- `.drawer__handle-bar` - Visible handle bar
- `.drawer__close-trigger` - Close button element

#### Placement Classes [!toc]

- `.drawer__content--bottom` / `.drawer__dialog--bottom` - Enters from the bottom (default)
- `.drawer__content--top` / `.drawer__dialog--top` - Enters from the top
- `.drawer__content--left` / `.drawer__dialog--left` - Enters from the left
- `.drawer__content--right` / `.drawer__dialog--right` - Enters from the right

### Data Attributes and States

The parts expose state through data attributes including:

- `[data-placement]` - Current placement (`top`, `bottom`, `left`, or `right`)
- `[data-entering]` and `[data-exiting]` - Open and close transitions
- `[data-active-snap-point]` and `[data-snap-points]` - Current and configured snap points
- `[data-dragging]` - Pointer dragging is active
- `[data-detached]`, `[data-handle-only]`, `[data-modal]`, and `[data-nested]` - Root modes
- `[data-drawer-snap-points="true"]` and `--snap-point-height` - Snap-point layout state
- `[data-drawer-background-scaled="true"]` - A background target is scaled while a drawer is open

## API Reference

### Drawer / Drawer.Root

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `children` | `ReactNode` | - | Trigger and overlay parts |
| `isOpen` | `boolean` | - | Controlled open state |
| `defaultOpen` | `boolean` | `false` | Initial uncontrolled open state |
| `onOpenChange` | `(isOpen: boolean) => void` | - | Called when the open state changes |
| `placement` | `"top" \| "bottom" \| "left" \| "right"` | `"bottom"` | Edge from which the panel enters |
| `snapPoints` | `readonly DrawerSnapPoint[]` | `[]` | Strictly increasing panel extents |
| `fadeFromIndex` | `number` | `0` | First snap point that shows the backdrop; lower points hide it |
| `defaultActiveSnapPoint` | `DrawerSnapPoint` | Last point | Initial uncontrolled snap point |
| `activeSnapPoint` | `DrawerSnapPoint` | - | Controlled active snap point |
| `onActiveSnapPointChange` | `(point: DrawerSnapPoint) => void` | - | Called when the active point changes |
| `closeThreshold` | `number` (`0` to `1`) | `0.25` | Drag distance fraction required to dismiss |
| `isDetached` | `boolean` | `false` | Adds an inset margin and rounded corners |
| `isDismissable` | `boolean` | `true` | Allows backdrop, Escape, and drag dismissal |
| `isHandleOnly` | `boolean` | `false` | Restricts dragging to `Drawer.Handle` |
| `isModal` | `boolean` | `true` | Uses modal focus and backdrop behavior |
| `shouldScaleBackground` | `boolean` | `false` | Scales elements marked `data-drawer-background` |
| `onDrag` / `onRelease` | `(event) => void` | - | Called while dragging and when a drag ends or is cancelled |
| `onClose` | `() => void` | - | Called after the root requests closing |
| `state` | `UseOverlayStateReturn` | - | Controls open state externally |

### Drawer.Trigger

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `children` | `ReactNode \| (values) => ReactNode` | - | Trigger button content |
| `className` | `string \| (values) => string` | - | Trigger button CSS classes |

`Drawer.Trigger` renders a React Aria `Button` with the `.drawer__trigger` class and forwards Button
props. To use an existing pressable such as `Button` as the trigger, place it directly inside
`Drawer` instead of wrapping it in `Drawer.Trigger`.

### Drawer.Backdrop

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `children` | `ReactNode` | - | Content wrapper and dialog |
| `className` | `string \| (values) => string` | - | Backdrop CSS classes |
| `variant` | `"opaque" \| "blur" \| "transparent"` | `"opaque"` | Visual backdrop treatment |
| `onClick` | `(event) => void` | - | Additional click handler |
| `isDismissable` | `boolean` | Root value | Overrides the root `isDismissable` for backdrop and drag dismissal |

React Aria ModalOverlay props (such as `isKeyboardDismissDisabled`) are forwarded in modal mode.
`Drawer.Backdrop` can also be used without `Drawer.Root` by passing `isOpen` and `onOpenChange`.

### Drawer.Content

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `children` | `ReactNode` | - | Dialog container content |
| `className` | `string \| (values) => string` | - | Content CSS classes |
| `placement` | `"top" \| "bottom" \| "left" \| "right"` | Root value | Overrides the root `placement` for this panel |

React Aria Modal props are forwarded. Left and right panels default to `w-80` (`sm:w-96`); a width
set on either `Drawer.Content` or `Drawer.Dialog` overrides it.

Motion can be tuned with `--drawer-duration` and `--drawer-ease`, or per phase with
`--drawer-enter-duration`, `--drawer-exit-duration`, `--drawer-enter-ease`, and `--drawer-exit-ease`.
Set them on `Drawer.Content` or an ancestor.

### Drawer.Dialog

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `children` | `ReactNode` | - | Panel content |
| `className` | `string` | - | Dialog CSS classes |
| `style` | `CSSProperties` | - | Additional inline styles |
| `aria-label` / `aria-labelledby` | `string` | - | Accessible name for the dialog |

The content panel receives the active snap point as its height (top/bottom) or width (left/right).

### Drawer.Handle

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `className` | `string` | - | Handle CSS classes |
| `aria-label` | `string` | `"Adjust drawer size"` | Accessible name for keyboard resizing |

With two or more snap points the handle has `role="button"` and `tabIndex={0}`. Click or use Arrow
Up/Right to move to the next snap point, or Arrow Down/Left to move to the previous point. Without
snap points it is a decorative drag affordance (`aria-hidden`).

### Drawer.Header, Drawer.Body, and Drawer.Footer

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `children` | `ReactNode` | - | Part content |
| `className` | `string` | - | Part CSS classes |

These parts are div-like elements and accept the corresponding DOM attributes.

### Drawer.Heading

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `children` | `ReactNode` | - | Accessible dialog title |
| `className` | `string` | - | Heading CSS classes |

The heading is rendered in React Aria's `title` slot.

### Drawer.CloseTrigger

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `children` | `ReactNode` | Built-in close icon | Close button content |
| `className` | `string \| (values) => string` | - | Close button CSS classes |
| `onPress` | `(event) => void` | - | Additional press handler |

Pressing it closes the current drawer.

### useOverlayState

Use `useOverlayState` with the root `state` prop when a parent owns the open state:

The Root also exposes `isOpen`, `defaultOpen`, and `onOpenChange` directly for controlled or
uncontrolled open state when a separate `useOverlayState` object is not needed.

```tsx
"use client";

import {Button, Drawer, useOverlayState} from "@sy-inc/react";

export function ControlledDrawer() {
  const state = useOverlayState({defaultOpen: false});

  return (
    <>
      <Button onPress={state.open}>Open Drawer</Button>
      <Drawer state={state}>
        <Button variant="secondary">Open Drawer</Button>
        <Drawer.Backdrop>
          <Drawer.Content>
            <Drawer.Dialog>
              <Drawer.Heading>Controlled Drawer</Drawer.Heading>
              <Drawer.CloseTrigger />
            </Drawer.Dialog>
          </Drawer.Content>
        </Drawer.Backdrop>
      </Drawer>
    </>
  );
}
```

The returned state exposes `isOpen`, `open()`, `close()`, `toggle()`, and `setOpen()`.

## Accessibility

Drawer is built on React Aria's dialog and modal primitives:

- **Dialog semantics**: Use `Drawer.Heading` or an explicit `aria-label`/`aria-labelledby` so the
  panel has an accessible name.
- **Focus and keyboard behavior**: Modal drawers use the React Aria focus containment behavior;
  `Escape` dismisses when `isDismissable` is `true`.
- **Keyboard resizing**: With snap points, `Drawer.Handle` is a labeled button-like control with
  arrow-key snap point navigation; otherwise it is hidden from assistive technology.
- **Reduced motion**: Drawer transitions are disabled when `prefers-reduced-motion: reduce` is set.
- **Non-modal mode**: Set `isModal={false}` intentionally when background content should remain
  interactive; the backdrop becomes transparent and pointer-events are disabled.
- **Drag safety**: Text fields, links, buttons, and `Drawer.Body` are excluded from regular drag
  starts. Set `isHandleOnly` when only the handle should begin a drag.
- **Drag gestures**: A drag starts after 8px of movement, so taps don't nudge the panel. The panel
  only moves toward dismissal unless a larger snap point exists, a cancelled pointer (for example,
  the browser taking over a gesture) snaps it back without closing, and a nested drawer drags
  independently of its parent. `onDrag` and `onRelease` fire only for gestures that became a drag.
