description: Card-like checkbox options for selecting multiple values.
---

## Usage

```tsx
import {CheckboxButtonGroup, Description, Label} from "@sy-inc/react";
```

```tsx
<CheckboxButtonGroup aria-label="Features" defaultValue={["security"]}>
  <CheckboxButtonGroup.Item value="security">
    <CheckboxButtonGroup.Indicator />
    <CheckboxButtonGroup.ItemContent>
      <Label>Security</Label>
      <Description>Real-time threat detection and prevention</Description>
    </CheckboxButtonGroup.ItemContent>
  </CheckboxButtonGroup.Item>
</CheckboxButtonGroup>
```

`Root`, `Item`, `Indicator`, `ItemContent`, and `ItemIcon` are available on `CheckboxButtonGroup`. Compose item text from `Label` and `Description`; the latter is included in the checkbox description automatically.

## Props and events

The root accepts all `CheckboxGroup` props. `value`, `defaultValue`, and `onChange` manage a string array; `isDisabled` disables every item. `layout` is `"flex"` by default and accepts `"grid"` for consumer-defined grid columns.

Each `Item` accepts `Checkbox` props, including `value`, `isDisabled`, and render-prop children. `Indicator` with no children reuses the standard checkbox control and checkmark. Custom children appear only while the item is selected.

`variant` defaults to `"secondary"`; pass a Checkbox variant when needed. The root ref resolves to the underlying group and item refs resolve to their Checkbox fields. Card children may read `isSelected` through a render prop.

The group does not set width or grid columns. Set them on the root, for example `className="max-w-[360px]"` or `className="sm:grid-cols-3"`.

## Anatomy

`CheckboxButtonGroup.Root` is the `CheckboxGroup` root. `Item` is a card-like `Checkbox`; `Indicator` is either the default checkbox control or a selected-only custom icon. `ItemContent` and `ItemIcon` are plain `span` parts for content and leading icons.

| Prop | Default | Description |
| --- | --- | --- |
| `value` | — | Controlled selected string array. |
| `defaultValue` | — | Initial selected string array. |
| `onChange` | — | Receives the next selected string array. |
| `isDisabled` | `false` | Disables every item. |
| `layout` | `"flex"` | Use `"grid"` with consumer grid columns. |
| `variant` | `"secondary"` | Checkbox visual variant inherited by items. |
| `className` | — | Root or part class override. |

## Examples

Copy these shared imports and helper once before any individual example:

```tsx
import {useState} from "react";
import {Icon} from "@iconify/react";
import {CheckboxButtonGroup, Description, Label} from "@sy-inc/react";
const Option = ({value, title}: {value: string; title: string}) => <CheckboxButtonGroup.Item value={value}><CheckboxButtonGroup.Indicator /><CheckboxButtonGroup.ItemContent><Label>{title}</Label><Description>Example description</Description></CheckboxButtonGroup.ItemContent></CheckboxButtonGroup.Item>;
```

### Default
```tsx
<CheckboxButtonGroup defaultValue={["security"]}><Label>Select features</Label><Option value="security" title="Security" /></CheckboxButtonGroup>
```
### Grid Layout
```tsx
<CheckboxButtonGroup className="grid-cols-3" layout="grid"><Label className="col-span-full">Add-ons</Label><Option value="backup" title="Backups" /></CheckboxButtonGroup>
```
### No Indicator
```tsx
<CheckboxButtonGroup><CheckboxButtonGroup.Item value="analytics"><CheckboxButtonGroup.ItemContent><Label>Analytics</Label><Description>Usage reports</Description></CheckboxButtonGroup.ItemContent></CheckboxButtonGroup.Item></CheckboxButtonGroup>
```
### Custom Indicator
```tsx
<CheckboxButtonGroup defaultValue={["updates"]}><CheckboxButtonGroup.Item value="updates"><CheckboxButtonGroup.Indicator><Icon icon="gravity-ui:circle-check-fill" /></CheckboxButtonGroup.Indicator><CheckboxButtonGroup.ItemContent><Label>Product updates</Label></CheckboxButtonGroup.ItemContent></CheckboxButtonGroup.Item></CheckboxButtonGroup>
```
### Icon Cards
```tsx
<CheckboxButtonGroup><CheckboxButtonGroup.Item value="2fa"><CheckboxButtonGroup.ItemIcon><Icon icon="gravity-ui:lock" /></CheckboxButtonGroup.ItemIcon><CheckboxButtonGroup.ItemContent><Label>2FA</Label><Description>Two-factor authentication</Description></CheckboxButtonGroup.ItemContent></CheckboxButtonGroup.Item></CheckboxButtonGroup>
```
### With Icons
```tsx
<CheckboxButtonGroup className="grid-cols-2" layout="grid"><CheckboxButtonGroup.Item value="content"><CheckboxButtonGroup.ItemIcon><Icon icon="gravity-ui:cloud" /></CheckboxButtonGroup.ItemIcon><CheckboxButtonGroup.ItemContent><Label>Content Management</Label></CheckboxButtonGroup.ItemContent></CheckboxButtonGroup.Item></CheckboxButtonGroup>
```
### Disabled Group
```tsx
<CheckboxButtonGroup isDisabled><Label>Select features</Label><Option value="security" title="Security" /></CheckboxButtonGroup>
```
### With Press Feedback
```tsx
<CheckboxButtonGroup><CheckboxButtonGroup.Item className="checkbox-button-group__item--pressable" value="github"><CheckboxButtonGroup.Indicator /><CheckboxButtonGroup.ItemContent><Label>GitHub</Label></CheckboxButtonGroup.ItemContent></CheckboxButtonGroup.Item></CheckboxButtonGroup>
```
### Render Prop Children
```tsx
<CheckboxButtonGroup><CheckboxButtonGroup.Item value="backup">{({isSelected}) => <><CheckboxButtonGroup.Indicator /><CheckboxButtonGroup.ItemContent><Label>Backups</Label>{isSelected ? "Selected" : ""}</CheckboxButtonGroup.ItemContent></>}</CheckboxButtonGroup.Item></CheckboxButtonGroup>
```
### Controlled
```tsx
const [value, setValue] = useState<string[]>(["backup"]); <CheckboxButtonGroup value={value} onChange={setValue}><Option value="backup" title="Backups" /></CheckboxButtonGroup>
```
### Subscription Plans
```tsx
<CheckboxButtonGroup defaultValue={["silver"]}><CheckboxButtonGroup.Item className="data-[selected=true]:ring-success" value="silver"><CheckboxButtonGroup.Indicator><Icon icon="gravity-ui:circle-check-fill" /></CheckboxButtonGroup.Indicator><CheckboxButtonGroup.ItemContent><Label>Silver</Label><Description>US$0.20/day</Description></CheckboxButtonGroup.ItemContent></CheckboxButtonGroup.Item></CheckboxButtonGroup>
```

## Accessibility

Provide an accessible name with `aria-label` or `Label`. The component preserves React Aria checkbox semantics: keyboard users can tab to a card and press Space to toggle it. Disabled cards are non-interactive.

## Styling

Classes: `.checkbox-button-group`, `.checkbox-button-group--grid`, `.checkbox-button-group__item`, `.checkbox-button-group__item--pressable`, `.checkbox-button-group__indicator`, `.checkbox-button-group__item-content`, and `.checkbox-button-group__item-icon`. The card body comes from the shared `choice-card` utility, which `radio-button-group` also uses.

Stable data slots: `checkbox-button-group`, `checkbox-button-group-item`, `checkbox-button-group-indicator`, `checkbox-button-group-item-content`, and `checkbox-button-group-item-icon`. The card radius can be themed with `--checkbox-button-group-item-radius`.

The Storybook examples cover Default, Grid Layout, No Indicator, Custom Indicator, Icon Cards, With Icons, Disabled Group, With Press Feedback, Render Prop Children, Controlled, and Subscription Plans. The press-feedback example applies the documented `checkbox-button-group__item--pressable` card modifier: `pressable-feedback` cannot be nested here because its root is a Button, which would add a second focusable control inside the card.
