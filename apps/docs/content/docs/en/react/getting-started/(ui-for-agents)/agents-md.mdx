Download SY INC v3 React documentation directly into your project for AI assistants to reference.

<Callout>
  **Note:** The `agents-md` command is specifically for SY INC React v3. Other CLI commands (like `add`, `init`, `upgrade`, etc.) are for SY INC v2 (for now).
</Callout>

### Usage

```bash
npx sy-inc-cli@latest agents-md --react
```

Or specify output file:

```bash
npx sy-inc-cli@latest agents-md --react --output AGENTS.md
```

### What It Does

- Downloads latest SY INC v3 React docs to `.sy-inc-docs/react/`
- Generates an index in `AGENTS.md` or `CLAUDE.md`
- Includes demo files for code examples
- Adds `.sy-inc-docs/` to `.gitignore` automatically

### Options

- `--react` - Download React docs only
- `--output <files...>` - Target file(s) (e.g., `AGENTS.md` or `AGENTS.md CLAUDE.md`)
- `--ssh` - Use SSH for git clone

### Requirements

- Tailwind CSS >= v4
- React >= 19.0.0
- `@sy-inc/react >= 3.0.0` or `@latest`
